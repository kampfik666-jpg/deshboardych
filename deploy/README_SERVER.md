# Миграция на VPS — что делать на сайте и что прислать мне

## 1. Заказ VPS на Aeza (5 минут)
1. Открой **aeza.net** → регистрация (email + пароль).
2. Серверы → **Аренда VPS** → выбери **KVM** (не Virtual Economy, если есть выбор).
3. Тариф: **NVMe 1–2 ГБ RAM** (от ~150–250 ₽/мес). Диск от 10 ГБ.
4. ОС: **Ubuntu 24.04** (это важно!).
5. Локация: **Европа** (Франкфурт/Амстердам) — Telegram работает стабильнее.
6. Оплати картой РФ.

## 2. Доступ к серверу
После оплаты Aeza покажет:
- **IP адрес** сервера
- **root пароль** (или придёт на почту)

## 3. Что прислать мне
Просто напиши в чат:
```
IP: 1.2.3.4
Пароль: xxxxxxxx
Порт SSH: 22 (если другой — укажи)
```
Дальше я всё сделаю сам:
1. Зайду на сервер по SSH (Windows имеет ssh.exe из коробки, либо поставлю paramiko)
2. Поставлю Python, ffmpeg, файрвол
3. Залью проект (код + база + загрузки, без виртуального окружения)
4. Создам systemd-сервис (автозапуск, авторестарт)
5. Проверю что бот и мини-апп работают
6. Настрою ежедневный бэкап базы (7 дней)

## 4. Что будет НЕ как на ПК
- Вместо `py run.py` — сервис в фоне 24/7, `systemctl status deshboardych`
- Логи: `journalctl -u deshboardych -f`
- Бэкапы базы: `/opt/deshboardych/backups/`
- Мини-апп по-прежнему через Cloudflare-туннель (ссылку обновит сама кнопка в боте)
- Дашборд доступен с телефона и из любой точки мира (защищён токеном)
