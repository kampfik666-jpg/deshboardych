# Life Hub — личный дашборд и «второй мозг»

Веб-дашборд + Telegram-бот, которые собирают в одном месте:

- 📅 **Календарь** — Яндекс 360 и Google Calendar (CalDAV)
- 📬 **Почту** — Яндекс Почта и Gmail (IMAP)
- ✅ **Задачи** — веб + Telegram (+ импорт из старого `personal-notes-bot`)
- 💳 **Платежи и обязательства** — автоматически извлекаются из твоих документов
- 📄 **«Второй мозг»** — кидаешь боту PDF (договор аренды, страховка, ОСАГО, квитанции),
  потом спрашиваешь: *«когда платить за свет?»*, *«до какого числа ОСАГО?»* — отвечает по документам
- ☀️ **Утренний брифинг** — каждый день в 6:00 (настраивается) погода, календарь, платежи, задачи, почта

Всё хранится локально на твоём ПК (SQLite + папка `data/`).

## Быстрый старт

```powershell
cd life-hub
py -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env   # затем заполни .env (см. ниже)
py run.py
```

Дашборд откроется на **http://127.0.0.1:8765**

> Чтобы приложение работало 24/7 и брифинг приходил вовремя, ПК должен быть включён
> (или добавь `py run.py` в автозапуск / планировщик Windows).

## Настройка .env

### 1. Telegram-бот (обязательно для брифингов и «второго мозга» в чате)
1. В Telegram напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи токен → `BOT_TOKEN=...`
2. Напиши своему боту `/start`, затем `/id` — он вернёт твой ID → `TELEGRAM_CHAT_ID=...`

> ⚠️ Один токен = один запущенный бот. Если старый `personal-notes-bot` работает на Render
> с тем же токеном — останови его, либо создай для Life Hub отдельного бота.

### 2. LLM для ответов по документам (рекомендуется)
Любой OpenAI-совместимый API:
```env
LLM_API_KEY=sk-...
LLM_BASE_URL=https://api.openai.com/v1   # или https://openrouter.ai/api/v1, или свой прокси
LLM_MODEL=gpt-4o-mini
```
Без ключа система тоже работает: платежи ищутся регулярками, вопросы — полнотекстовым поиском,
брифинг собирается по шаблону.

### 3. Яндекс 360 (почта + календарь)
1. Включи IMAP: Яндекс Почта → Настройки → «Почтовые программы» → включи IMAP.
2. Создай **пароль приложения**: id.yandex.ru → Безопасность → Пароли приложений → тип «Почта/Календарь».
3. В `.env`:
```env
YANDEX_ENABLED=true
YANDEX_LOGIN=твой_логин@yandex.ru
YANDEX_APP_PASSWORD=xxxxxxxxxxxxxxxx
```

### 4. Google (Gmail + Calendar)
1. Включи двухэтапную аутентификацию в Google Аккаунте.
2. Создай **пароль приложения**: myaccount.google.com → Безопасность → Пароли приложений.
3. Включи IMAP: Gmail → Настройки → Пересылка и POP/IMAP.
4. В `.env`:
```env
GOOGLE_ENABLED=true
GOOGLE_EMAIL=твой@gmail.com
GOOGLE_APP_PASSWORD=xxxx xxxx xxxx xxxx
```

### 5. Остальное
- `BRIEFING_TIME=06:00` — во сколько присылать брифинг
- `TIMEZONE=Asia/Yekaterinburg` — твой часовой пояс
- `SYNC_EVERY_MINUTES=30` — как часто обновлять почту и календарь
- `WEATHER_CITY=Екатеринбург` — город для погоды (пусто = без погоды)

## Как пользоваться

### Telegram-бот
| Действие | Как |
|---|---|
| Сохранить документ | просто пришли PDF/DOCX/TXT боту |
| Задать вопрос | напиши текст: «когда платить за свет?» |
| Брифинг сейчас | `/brief` |
| Что на сегодня | `/today` |
| Ближайшие платежи | `/pay` |
| Задачи | `/tasks`, добавить: `/add Купить лампочку 2026-11-10`, закрыть: `/done 12` |
| Синхронизация | `/sync` |
| Статус подключений | `/status` |

### Веб-дашборд
- **Сегодня** — последний брифинг, события дня, платежи, задачи, почта
- **Календарь** —agenda на 3 недели из всех календарей
- **Почта** — последние письма, фильтр «непрочитанные»
- **Задачи** — добавление/выполнение
- **Платежи** — все обязательства с датами, отметка «оплачено»
- **Документы** — загрузка файлов, поиск по содержимому
- **Спросить** — чат со «вторым мозгом»
- **Подключения** — статус сервисов и последней синхронизации

## Структура проекта

```
life-hub/
├─ run.py                 # точка входа: веб + бот + планировщик
├─ app/
│  ├─ main.py             # запуск uvicorn, бота и планировщика в одном процессе
│  ├─ config.py           # настройки из .env
│  ├─ db.py               # SQLite-схема и хелперы
│  ├─ documents.py        # загрузка/извлечение текста/поиск по документам
│  ├─ obligations.py      # платежи и сроки (LLM + запасной regex-вариант)
│  ├─ brain.py            # ответы на вопросы по твоим данным
│  ├─ briefing.py         # утренний брифинг (+погода open-meteo)
│  ├─ scheduler.py        # APScheduler: брифинг в 6:00, синк каждые 30 мин
│  ├─ telegram_bot.py     # команды, приём документов, вопросы
│  ├─ api.py              # REST API для веб-дашборда
│  ├─ importer.py         # перенос задач из personal-notes-bot
│  ├─ integrations/       # CalDAV (календари) и IMAP (почта)
│  └─ static/             # веб-интерфейс
└─ data/                  # база, загруженные файлы, лог (не в git)
```

## Примечания и ограничения
- Сканы без текстового слоя (фото документов) пока не распознаются — нужен PDF с текстом.
- Gmail/Google из РФ могут требовать VPN на уровне сети твоего ПК.
- База `data/lifehub.sqlite3` — просто бэкапь эту папку.
